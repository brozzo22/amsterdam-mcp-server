Amsterdam MCP server and open data

A free, read-only Model Context Protocol server for Amsterdam, run by Essentially Amsterdam, a daily English-language newsletter, events calendar, news, jobs board and business directory.

Connect

Endpoint: https://essentiallyamsterdam.com/mcp. Server page: https://essentiallyamsterdam.com/mcp-server/.

claude mcp add -t http essentially-amsterdam https://essentiallyamsterdam.com/mcp

What it can answer

  • Events on a given day, from the What's on calendar
  • English-language jobs in the Amsterdam area
  • Local businesses from the business directory
  • Markets open today, upcoming conferences and recent news
  • Dutch net salary and rent points, and whether a Museumkaart pays off

Open datasets

  • Bike and moped theft per neighbourhood
  • Public toilets in Amsterdam
  • Playgrounds in Amsterdam

More free tools: https://essentiallyamsterdam.com/tools/.
